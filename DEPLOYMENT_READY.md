## 🚀 **Quick Start Deployment:**

### **1. Backend (Render) - 5 minutes**
1. Go to [render.com](https://render.com)
2. Connect GitHub → Select `connectspace` repo
3. Root Directory: `backend`
4. Add environment variables from template
5. Deploy!

### **2. Frontend (Vercel) - 3 minutes**
1. Go to [vercel.com](https://vercel.com)  
2. Import `connectspace` repo
3. Root Directory: `frontend`
4. Add `REACT_APP_API_URL` with your Render URL
5. Deploy!

### **3. Connect Both - 1 minute**
1. Update `CORS_ORIGIN` in Render with Vercel URL
2. Test the connection
3. 🎉 You're live!
